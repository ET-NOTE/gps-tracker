# 간편 HTTP 학습: 코드를 붙여 넣고 LTE 상태 보내기

1NCE 예제를 수정 없이 업로드하고 시리얼에 24시간 교육용 전송 코드를 붙여 넣습니다. 본인 장치에 LTE 상태만 보내는 HTTP 학습 예제입니다.

## 본인 장치와 HTTP 학습 연결 준비

먼저 [간편 HTTPS](/examples/shield-uno-easy-https) 또는 [첫 서버 전송](/examples/shield-uno-first-upload) 예제를 그대로 업로드하고 시리얼 등록 코드로 내 장치에 연결하세요. 이미 등록한 보드는 이 과정을 반복하지 않습니다.
[내 장치](/devices)에서 본인 장치를 선택하고 HTTP 학습 연결 → 24시간 켜고 전송 코드 받기를 누릅니다. demo-로 시작하는 전체 코드를 복사하세요. 관리자 작업은 필요 없습니다.
! 교육용 전송 코드는 웹 장치 등록 코드와 다릅니다. HTTP는 암호화되지 않아 코드를 아는 사람이 만료 전까지 학습용 상태를 보낼 수 있습니다. 위치·개인정보·운영 센서 값은 보내지 마세요.
(이미지) 값을 가린 HTTP 학습 연결 화면.

## 전체 ZIP 그대로 업로드

아래 v3 전체 ZIP을 새 폴더에 풀고 08_shield_http_pairing/08_shield_http_pairing.ino를 엽니다. src 폴더를 유지합니다.
1NCE APN이 포함되어 있으므로 설정 파일을 만들거나 값을 수정할 필요가 없습니다. Arduino AVR Boards → Arduino Uno와 실제 포트를 선택해 그대로 업로드합니다.
[Arduino 설치](/examples/arduino-basics-install) · [COM 포트 확인](/examples/arduino-basics-com-port) · [업로드 방법](/examples/arduino-basics-upload)을 참고하세요. 인증서·Python·브리지 스케치는 필요 없습니다.
(이미지) Arduino IDE의 파일 구성과 업로드 화면.

## 시리얼에 전송 코드 붙여 넣기

시리얼 모니터를 115200 baud · 새 줄로 설정합니다. [CODE] 안내가 나오면 웹에서 복사한 demo-로 시작하는 전체 교육용 전송 코드를 붙여 넣고 전송합니다.
[CODE] Accepted 후 LTE 연결을 기다립니다. [HTTP] 200이 나오면 [내 장치](/devices)에서 같은 장치의 마지막 수신을 확인하세요.
실제 LTE 신호·망 등록 상태·가동 시간만 보냅니다. 센서 카드와 지도에 값이 없어도 정상입니다. 기본 주기는 60초 대기와 통신 처리 시간입니다.
입력한 코드는 RAM에만 보관하므로 UNO를 리셋하거나 시리얼 모니터를 다시 열어 보드가 리셋되면 다시 붙여 넣습니다. 펌웨어 수정이나 재업로드는 필요 없습니다.
! UNO 컴파일·모뎀 응답 시뮬레이션·격리 서버 검증과 실물 검증은 다릅니다. 이 버전의 실제 LTE 전송은 확인 전입니다.
(이미지) 코드를 가린 시리얼 출력과 마지막 수신 화면.

## 종료·만료와 HTTPS로 확장

학습 종료 시 HTTP 학습 연결 → 학습 연결 끄기를 누릅니다. 24시간이 지나거나 새 코드를 받으면 이전 코드는 만료됩니다.
401이 나오면 웹에서 새 교육용 전송 코드를 받고 시리얼 모니터에 다시 붙여 넣습니다. 새 코드를 받는 화면을 닫으면 같은 코드를 다시 조회할 수 없습니다.
429는 15분 대기합니다. [STOP]은 전원·USIM·안테나를 점검한 뒤 리셋합니다.
센서·GPS 또는 운영 데이터는 HTTPS를 사용하세요. [DHT11 HTTPS 전송](/examples/shield-uno-upload)으로 바꿔 올려도 EEPROM의 기존 HTTPS 장치 연결은 유지됩니다. HTTP 예제는 그 저장 정보를 읽거나 지우지 않습니다.


## 보호 범위

장기 HTTPS 연결 정보는 읽거나 전송하지 않습니다. 서버는 이 HTTP 경로에서 LTE 상태 외의 GPS·센서 값을 거부합니다.
