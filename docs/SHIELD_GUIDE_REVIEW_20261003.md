# Shield 시작 가이드 검토 · 2026-10-03

## 검토 결과

- 운영 `start` revision 8: 팀장이 올린 제목·5단계·4장 이미지가 정상 저장되어 있었다. 예제 파일과 기초 사용법 링크, 장치 UID/키·CA 설정 설명은 없었다.
- 기존 완성형 UNO 예제 5개는 공개되어 있었다. 첫 화면이 초기 seed 글을 앞에서 6개만 보여 주어 다운로드 없는 구버전이 먼저 노출됐다.
- 등록 전 전송은 409로 거절된다. 시작 순서를 연결 → 장치 등록 → 예제 업로드 → 수신 확인 → USIM 확인으로 바꾸고 사진의 단계 번호도 함께 이동했다.
- 센서 없는 시작 구성에 DHT11 전송 코드를 붙이면 따라 할 수 없다. 추가 센서 없이 실제 LTE CSQ/망 상태를 보내는 `06_first_upload`를 추가했다. GPS/온습도 전송으로 오인하지 않도록 안내한다.

## 변경

- `/guide`는 선택된 예제 제목 표시, breadcrumb 및 전체 예제/라이브러리 링크 제거. 사진 영역 흰색, 원본 크게 보기 링크.
- 시작 가이드 업로드 단계에 ZIP·INO·따라 하기 문서 3개. ZIP 안에 공통 드라이버, placeholder 설정, CA 도구 및 CA 설치용 01_connection도 포함.
- 실제 사진/기존 관리자 이미지 재사용. USIM 5단계에 비로그인 `/devices` 데모 화면 추가. 실제 단말·잔액이 아니라는 표기 유지.
- 기존 5개 예제에 실물 연결 사진, Arduino IDE 안내 및 기초 설치/포트/업로드 링크 추가. 센서 예제에는 DHT 라이브러리 설치 링크.
- 초기 seed `status/dht11/gnss/upload` 주소는 공개된 완성형으로 연결. 이후 관리자가 초기 글을 수정하면 그 편집본을 우선한다. DB 원문 삭제 없음.
- `/devices` 비로그인·빈 계정 데모 및 명시적 `?demo=1`. 인증 필요한 실제 API는 그대로 보호된다. `useDeviceList`의 세션 초기화 undefined → null 전환을 놓쳐 무한 로딩하던 문제 수정.
- 내 장치·요금 안내 두 곳에 USIM 충전 버튼. 데모는 안내만 표시하고 충전 API를 호출하지 않는다. 로그인 후 원래 요금 안내/장치 등록으로 복귀.
