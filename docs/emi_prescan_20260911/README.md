## 결론 (ON−OFF 차분)
1. **40MHz 클럭 고조파 콤 = 대책 1순위**: 39.7 / 80.1 / 118.9 / **159.3(+27dB, 전체 최대)** / 199.8 MHz
   — ESP32-C3 메인 XTAL 40MHz 고조파. KC 복사성 방출 대표 탈락 요인.
2. 9.7MHz 간격 콤 (608.8/618.5/628.2/637.9 MHz) + 저VHF 다수 — 전원부/디지털 스위칭 계열, 레벨은 1보다 낮음.
3. 833~843MHz = SIM7080G B5 상향 송신 버스트 (의도 출력, 스펙트럼으로도 B5 교차확인).
4. 883/891/874/966MHz 등 = 기지국 하향링크 배경 (단말 OFF 에도 존재). 345/361/796/922/948MHz
   의심 건은 배경 180s 누적에 흡수 → 외부 버스트(TRS/RFID) 확정.
5. 47.8MHz(+11.5dB, 큰 루프 20cm)는 근접 스캔에선 미재현 — 위치 의존, 보류.
