# 개인정보 권리 대응 11차 — 회사 처리 보고서·증빙

2026-11-05 · GPS 운영 반영 · `codex/location-business-prep`

## 결과와 사용 경로

관리자가 회사 검토 대장에서 본인 범위를 확인한 뒤, 해당 회사 소유 계정에 **처리 보고 요청**을 게시할 수 있다. 회사는 **내정보 → 개인정보 → 회사 자료 처리 요청**에서 실제 처리 결과와 증빙을 제출한다. 회사 명단의 관리자 역할이나 위임 헤더로 이 권한을 대신할 수 없다.

1. 플랫폼 관리자: 개인정보 요청 → 회사 자료 검토 대장 → 본인 범위 확인. 회사·명단 번호, 자료 종류, 기간을 확정한다.
2. 같은 항목의 **회사 처리 결과·증빙 → 회사에 처리 보고 요청**에서 공개 안내와 제출 기한을 입력하고 확인한다. 명단 번호 없는 범위나 이미 종료한 검토 항목에는 발행하지 않는다.
3. 회사 소유 계정: 지정 범위의 처리 결과(전달·정정·삭제 또는 제한), 실제 처리 시각, 건수, 처리 방법, 내부 작업 참조번호와 PDF/PNG/JPG 증빙 한 개를 제출한다.
4. 플랫폼 관리자: 최신 증빙을 내려받고 실제 처리 결과와 대조한 뒤 **보완 요청** 또는 **검토 결과 대장에 반영**한다. 보완 제출은 이전 파일을 덮어쓰지 않는다.
5. 반영 시 해당 검토 항목에 `company-task:{id}/submission:{id}`를 기록한다. 요청 전체의 완료는 별도 판단이다. 제한 결과는 `restricted`이며 전체 완료를 통과시키지 않는다.

회사 요청 게시 자체로 이메일·푸시를 보내지 않는다. 회사에 보이는 항목은 회사 자체 명단 번호, 자료 종류·기간, 요청 종류, 안내, 기한, 제출 내역과 회사용 피드백이다. 요청자 이메일·계정 번호·원문 요청·본인 확인 근거·내부 검토 사유·후보 집계는 제공하지 않는다. 관리자가 작성하는 회사용 안내에도 불필요한 개인정보를 넣지 않아야 한다.

## 경계와 제한

- 기존 회사·SIM·운행 원본을 자동 추출·정정·삭제하지 않는다. 이 기능은 회사의 실행 결과를 보고하고 검토하는 절차다. 파일 해시는 파일의 일치 확인용이며 실행 사실의 자동 증명이 아니다.
- 제출 가능 기간은 최대 14일, 기존 검토 범위는 최대 366일이다. 범위당 발행 3회, 요청당 제출 5회, 파일당 2MiB, 회사당 보존 증빙 합계 64MiB로 제한한다. 한도를 넘으면 담당자가 범위를 재검토한다.
- PDF/PNG/JPG 형식·헤더·크기·파일명을 확인하고, JSON 요청 본문은 3MiB로 제한한다. 첨부 원문은 별도 DB `BYTEA`에 보관한다. 목록·공개 API에 원문을 포함하지 않는다. 웹에서 직접 렌더링하지 않고 `attachment`, `application/octet-stream`, `nosniff`, `no-store`로 제공한다. 파일 전체의 악성 여부를 검사하는 기능은 이번 범위에 없다.
- 증빙 제출과 사건 기록은 변경·삭제 방지 트리거로 보호한다. 보관 기간 확정 후의 별도 파기 절차는 열린 항목이다. 영구 보관이나 익명화로 확정한 것이 아니다. 계정 종료 처리기는 요청자·회사 소유자 모두의 증빙 잔존을 집계하고 `company_evidence_retention_review`로 표시한다.
- 부모 요청 → 회사 검토 → 제출 요청 순서로 잠그고 revision을 확인한다. 회사별 용량 집계도 동시 제출을 직렬화한다. 같은 제출의 동시 전송은 하나만 저장한다.
- 관리자 본인이 최신 증빙을 내려받은 기록, 최신 제출 번호·해시, 내용 확인 체크와 회사/요청자 안내가 있어야 반영한다. 회사가 내려받은 기록, 이전 증빙 확인, 다른 관리자의 확인으로 대신하지 않는다.
- 진행 중인 회사 제출 요청이 있으면 기존 대장 PATCH로 검토를 건너뛸 수 없다. DB에서도 미승인 제출·잘못된 참조/결과의 종료 상태를 거부한다.
- 회수하면 회사 접근을 끊고 검토 항목을 대기로 돌린다. 만료·부모 요청 취소/종료·회사 계정 이용 종료 후 회사 조회·다운로드·제출과 신규 승인도 차단한다. 플랫폼 관리자는 보관 검토를 위해 증빙 이력을 계속 조회할 수 있다.
- 증빙 응답 생성은 작업별/계정별 15분 30회 제한이다. 응답 생성 기록을 사용자 파일 열람·내용 확인의 자동 증명으로 표현하지 않는다. 이미 내려받은 사본은 원격 회수할 수 없다.
