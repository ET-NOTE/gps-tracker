# 132차 — 귀속 미상 위치·이벤트의 읽기 전용 분류 조회

2026-11-15 KST. **구현·기능 검증 완료 / 운영 미배포.** [기존 최소변경 정책](location-rights-minimal-change-policy.md)의 NULL 귀속 자료 목록 작업을 진행했다. 사용자 결정대로 부하 검증은 추가하지 않았다. 코드 `f060bab012bb6a6ffbc4e7d6657c5d29b03bdaf6`, API `8c53686cd1f15ee5b9dbcbbcd385fb7369e05ddbc49be8dc95d6afbfc3fa4bee`, 스키마114 유지. 마지막 확인 운영은99이며 이번에 운영 서버에 접속하지 않았다.

## 제공 기능

관리자 보안 화면에 ‘귀속 미상 자료 검토’를 추가했다. 수집 당시 계정(`user_id`)이 NULL인 물리 위치/이벤트 행을 한국시간 기록일·장치 번호·정규화한 수집 방식/이벤트별로 묶어 건수와 현재 장치 연결 유무를 표시한다. 현재 연결 계정의 이름·이메일·계정번호, 좌표, 복호화 자료, 이벤트 원문과 임의 입력된 source/kind 문자열은 응답에 포함하지 않는다. 임의 문자열은 ‘기타·확인 필요’로 분류한다.

`GET /admin/privacy/unattributed`는 자료 종류·시작/종료 시각을 필수로 받으며 최대31일의 반열린 구간을 조회한다. 웹 날짜는 한국시간·종료일 포함으로 변환한다. 선택 장치 필터와1~100개 분류의 페이지 제한(웹50)을 지원한다. 다음 페이지는 날짜/장치/분류 키와 조회 조건에 묶이며 조건이 바뀐 커서는 거부한다. 페이지 간 고정 스냅샷은 아니므로 자료 변경 후 처음부터 재조회하도록 안내한다. 화면 합계는 이번 페이지에 한정한다.

개인별 관리자 보안이 켜져 있어야 하며 책임자/관리자의 MFA·IP·권한·감사기록 검사를 통과해야 한다. 일반 사용자·취급자·위임 계정은 거부하고, 보안 OFF 상태의 구형 관리자도 거부한다. 감사기록 저장이 실패하면 자료를 내주지 않는다. 새 경로는 좌표 없는 관리 메타데이터로 분류하고 기존 관리자 접근기록에 남긴다. NULL을 익명화/파기 가능으로 판단하거나 현재 소유자에게 재귀속하지 않는다.

SQL은 기존 제한이 적용되는 읽기 전용 트랜잭션에서 물리 메타데이터만 읽는다. 전체 조회2개·기존 대기/20초 SQL 제한을 유지하고 요청 취소 시 SQL과 슬롯을 반환한다. 웹은 명시적으로 조회할 때만 요청하고 필터 변경·취소·화면 종료 시 요청을 중단한다. 늦은 응답은 무시하며, 오류를 ‘자료 없음’으로 보여주지 않는다. 응답은 `no-store, private`다. 자동 변경·삭제·내보내기·새 보관 정책·마이그레이션은 추가하지 않았다.
