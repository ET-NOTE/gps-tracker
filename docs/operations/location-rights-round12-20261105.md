# 개인정보 권리 대응 12차 — 검토한 본문 일부 제공

2026-11-05 · GPS 운영 반영 · `codex/location-business-prep`

## 결과와 사용 경로

채팅·AI 분석 본문에서 담당자가 선택한 구간만 요청자에게 제공한다. 선택하지 않은 부분은 `[비공개]`로 대체하며, 원문 전체를 기본 선택하지 않는다. 회사 증빙·사진·영수증은 이번 제공 대상에 포함하지 않는다.

1. 플랫폼 관리자: 개인정보 열람 요청을 검토 중/추가 확인 상태로 두고 기한을 지정한다. **본문 일부 제공**에서 해당 요청자에게 저장된 채팅 또는 AI 기록을 선택한다.
2. 원문을 확인하고 텍스트를 선택한 뒤 **선택한 부분만 추가**한다. 제공 범위와 제외 사유를 입력한다.
3. **제공본 미리보기**에서 실제 제공될 문장을 확인한다. 본인 범위·타인 정보 제외·미리보기 확인을 체크해야 발급할 수 있다. 선택 구간이나 안내를 수정하면 미리보기와 확인이 초기화된다.
4. 요청자: **내정보 → 개인정보 → 해당 요청 → 검토한 본문·일부 제공**에서 현재 비밀번호를 확인하고 JSON 파일을 저장한다. 비밀번호는 시도 후 화면에서 비운다.
5. 발급은 24시간 후 만료된다. 관리자는 먼저 회수할 수 있으며, 같은 원본에 다시 발급하면 이전 발급은 회수된다. 본문 발급만으로 요청 전체를 완료하지 않는다.

## 경계와 제한

- 채팅의 귀속은 `chat_threads.user_id`, AI의 귀속은 `ai_analyses.user_id`로 확인한다. 현재 SIM/단말기 소유자에게 이전 계정의 본문을 넘기지 않는다. 실제 SIM 관계와 운행 원본은 변경하지 않는다.
- 원문은 명시적인 관리자 확인 동작으로만 가져온다. 목록은 원문 없이 종류·시각·글자 수 등을 제공한다. 요청자용 목록에는 원본 번호·해시·선택 위치·관리자 번호를 노출하지 않는다.
- 원문당 최대 20,000 Unicode 문자, 선택 구간 1~50개, 안내 1~1,000자, 요청당 발급 50건으로 제한한다. 구간은 순서·중복·범위를 검사한다. 브라우저의 UTF-16 선택 위치를 Unicode 문자 위치로 변환해 이모지 주변도 올바르게 처리한다.
- 같은 관리자의 1시간 이내 원문 확인과 미리보기 이력이 필요하다. 발급은 요청 revision, 원문 해시, 구간·안내에 묶인 미리보기 해시, 명시적 확인을 함께 검사한다. 해시는 일치 확인용이며 본인 확인이나 타인 정보 검토의 정확성을 자동 증명하지 않는다.
- 다운로드 때도 원문의 현재 계정 귀속과 해시를 검사한다. 원문 변경·삭제·귀속 변경 시 기존 발급은 차단한다. 회수·만료·부모 요청 취소/거절·계정 이용 종료도 차단한다. 현재 비밀번호와 계정/IP별 요청 제한을 적용한다.
- 응답은 `attachment`, `application/octet-stream`, `nosniff`, `no-store, private`로 제공한다. 응답 생성 이력은 사용자가 실제 파일을 열었다는 증명이 아니다. 이미 내려받은 사본은 원격 회수할 수 없다.
- 원문과 제공 본문의 사본을 새로 저장하지 않는다. 원본 참조·해시·선택 범위·안내·검토/발급/회수/응답 생성 이력만 저장한다. 발급 정보는 회수 외 변경을 막고 사건 이력도 변경·삭제를 막는다.
- 선택 정보와 감사 이력도 개인정보에 해당할 수 있다. 익명화나 전체 파기 완료로 보지 않으며 보관 근거·기한과 승인된 파기 절차는 열린 항목이다. 안내에도 불필요한 개인정보를 넣지 않아야 한다.
