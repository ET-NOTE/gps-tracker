# 개인정보 권리 대응 14차 — 회사 영수증 원본 연결

2026-11-06 · GPS · `codex/location-business-prep`

## 이번에 완료한 범위

회사 지출에 저장된 PNG/JPG 영수증을 개인정보 열람 요청의 **확인된 회사·직원·지출일 범위**에서 직접 조회하고, 담당자가 공개할 영역을 선택해 24시간 제공한다. 13차의 수동 이미지 제공에 서버 원본 연결을 추가했다. 회사 공용 문서 전체를 자동 귀속시키거나 원본을 정정·파기하는 기능은 아니다.

1. 플랫폼 관리자 → 개인정보 요청 → 열람 요청을 검토 상태로 두고 처리 기한을 지정한다.
2. 회사 검토 대장에서 회사·직원 본인 관계를 확인한다. 자료 종류는 지출 또는 첨부 자료로 지정한다.
3. **사진·영수증·문서 일부 제공**에서 해당 회사 검토 범위를 선택한다.
4. **회사에 저장된 영수증 → 원본 확인·불러오기**로 이미지를 연다. 목록은 50개씩 조회한다.
5. 원본의 본인 영역을 드래그하거나 좌표로 지정하고 제공 범위·제외 사유를 적는다. 선택하지 않은 부분은 검게 제거한다.
6. 실제 제공 이미지와 원본 귀속을 각각 확인한 뒤 발급한다. 요청자는 현재 비밀번호를 확인하고 PNG를 내려받는다. 일부 발급만으로 요청 전체가 완료되지 않는다.

직접 준비한 개인 자료·PDF 페이지 이미지의 수동 제공 경로는 유지한다. **서버 원본 연결** 표시가 있는 자료만 이번 원본 재검증 대상이다.

## 범위와 원본 검증

- 회사 소유자, 확인된 직원 ID, 지출일, 지출·파일의 소유자 일치를 서버에서 확인한다. 다른 직원, 범위 밖 날짜, 취소된 지출, 제거 표시된 영수증, PDF 등은 직접 조회에서 제외한다.
- 지출일은 날짜 필드다. 검토 시작·종료 시각을 한국 날짜로 변환하여 **시작일 포함·종료일 제외**로 비교한다. 시각 단위 지출 귀속을 검증한 것으로 해석하지 않는다.
- 요청자 및 회사 계정의 이용 제한, 회사 검토 revision·본인 확인 상태를 읽기·미리보기·발급·다운로드마다 확인한다. 현재 SIM 소유권을 직원 귀속 판단에 사용하지 않는다.
- 원본 바이트의 SHA-256을 재계산한다. 영수증과 지출에 변경 revision을 추가하여 내용을 되돌리거나 제거 표시를 복구해도 과거 발급을 되살리지 않는다.
- 서버가 PNG/JPEG를 해석해 RGB PNG로 정규화한다. 브라우저에 보여주는 이미지와 제공본은 같은 픽셀 좌표계를 사용한다. JPEG EXIF 회전은 적용하지 않으므로 옆으로 표시될 수 있으나 선택과 출력 방향은 일치한다.
- 서버 원본 연결 시 클라이언트가 보낸 RGB를 신뢰하지 않고 저장된 원본에서 픽셀을 다시 만든다. 출력 PNG는 선택 영역만 포함하며 원본 메타데이터·알파·텍스트 레이어를 복사하지 않는다. 투명 영역은 흰색 배경으로 합성한다.
- 같은 관리자가 1시간 이내에 해당 원본·범위·revision을 읽은 기록과 같은 미리보기 기록이 있어야 발급할 수 있다. 원본을 처리한 뒤 범위를 다시 검사하고 읽기 응답 생성 이력을 남긴다. 이 기록은 사람이 실제 읽었다는 증명은 아니다.
- 원본 읽기 응답은 캐시하지 않는다. 원본과 출력 해시·revision·최소 읽기 이력만 보존하며 원본을 새 보관 테이블에 복제하지 않는다.

## 변경·제거 시 동작

지출 수정, 직원 변경, 영수증 수정·제거·삭제로 연결 조건이 달라지면 기존 다운로드가 차단된다. DB 트리거는 무효화된 **임시 제공 PNG**를 제거한다. 회사 검토 변경·계정 제한·회수·만료 처리는 13차 규칙을 그대로 적용한다.

원본 지출 원장과 영수증은 이 제공 기능이 수정하거나 삭제하지 않는다. 원래 영수증 제거 기능의 `removed_at` 표시는 원본 바이트의 물리 파기가 아니다. 이번에도 원본·감사 이력·백업까지 전체 파기 또는 익명화 완료라고 표시하지 않는다. 이미 받은 사본은 원격 회수할 수 없다.

## 제한과 남은 작업

- 직접 연결은 기존 영수증 저장 한도 5MiB 이내 PNG/JPG, 한 변 2048px·100만 화소 이하다. 대용량 휴대폰 사진은 현재 그대로 처리하지 못한다. APNG·CMYK JPEG·지원하지 않는 형식은 거부한다. 수동 준비 이미지의 기존 6MiB 한도는 별도다.
- 디코딩·인코딩 동시 작업 2개, 메모리·화소·본문 크기 제한을 적용한다. 요청당 10회·전체 임시 PNG 64MiB 한도와 24시간 만료를 유지한다.
- [ ] 큰 영수증의 안전한 축소·회전, PDF 다중 페이지 추출·OCR 보조 검토. → 축소·회전은 [15차](location-rights-round15-20261106.md)에서 개발·격리 검증(운영 미배포), PDF는 방식 결정 대기.

- [ ] 회사 원본 정정·파기: 처리 근거·보관 기간·승인 범위를 먼저 확정하고 자료 종류별로 연결.
