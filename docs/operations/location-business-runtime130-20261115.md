## 변경과 장애 재현

기준판은127 API에 계측만 더한 `fe5a5d3`, SHA `613041a15e52470da521e572222a961ad44fe545ae9815e014d120c5610a0150`다. 수정판 소스는 `e4c2dc5b4203fa32f17832c07a1b6c927b299d76`, API SHA `42d3e8768c66d280bc623fe7c3eb9a1a24bd63cddf635413a339886ec5e8bb59`다. 기준판에서 단일 위치 INSERT 뒤 통계 갱신 예약을 강제로 실패시키면 HTTP500·인증 카운터 롤백과 함께 **위치1행은 이미 저장**되는 것을 재현했다. 수정판은 위치와 통계 예약을 함께 롤백해 **위치0행·예약0행·최근 위치 없음·인증 카운터0**이며 같은 카운터의 정상 재시도를 수락한다. 두 개의 자동 커밋을 한 개로 줄이되 fsync·동기 커밋·암호화·SIM/개인정보 잠금은 유지한다.

보호 범위는 `insert_location`의 단일 위치와 통계 예약이다. 기존 배치 저장도 별도 트랜잭션을 유지한다. **요청 전체의 원자성이나 네트워크 전달의 정확히1회 처리를 구현한 것은 아니다.** 이후 후처리·응답/인증 커밋 실패 시 이미 저장한 위치가 남을 가능성은 별도 검토 대상이다. 모든 SQL을 바깥 인증 트랜잭션에 합치면 기존 단말 행/FK 잠금 순서에 영향을 주므로 임의로 합치지 않았다.

`gps_ingest_timing=debug`를 켤 때 고정 숫자 필드·마지막 단계·완료 여부만 남긴다. 새 계측에는 단말ID·좌표·본문·서명·키·SQL·연결문자열이 없다. 실행 허용 대기, JSON, DB 획득+BEGIN, 인증, 하드웨어/SIM/단말 잠금, 개인정보·수집 제어, 메타데이터, 배치/단일 저장, 후처리, 지오펜스, 수명 이벤트, 명령, 연결, 서명, 마지막 커밋을 구분한다. 오류는 `completed=false`이며 완료는 인증 트랜잭션 커밋까지의 처리 완료를 뜻한다. 상대 단말의 응답 수신을 증명하지는 않는다.

각 단계는 await·스케줄링을 포함한 순차 wall-clock 시간이다. `pool_begin_ms`는 순수 풀 대기가 아니며 `store_ms`는 트리거·예약·커밋도 포함한다. 각 p95를 더하지 않는다. CPU 스케줄링·WAL·물리 I/O를 이 숫자만으로 각각 확정할 수 없다.
