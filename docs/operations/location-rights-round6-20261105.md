# 위치정보 권리 처리 6차 — SIM별 위치 수집 중지·재개

2026-11-05. 기존 SIM 기준 논리 장치·계정·기록 구조를 유지하고, 이용자가 위치 수집을 중지하고 재개하는 기능을 추가했다. 기존 기록 삭제와 회원 탈퇴는 별도 절차다.

## 동작과 적용 경계

- **내정보 → 개인정보 요청 → 위치 수집**에서 소유한 GPS 단말기를 선택한다. 휴대폰 위치 송신기는 이번 대상에서 제외한다. 회사 직원의 위임 권한으로 소유자의 수집 설정을 변경하지 않는다.
- 중지 설정을 저장하면 SIM별 수집 잠금을 획득한 뒤 정책 버전을 변경한다. 이후 새 위치와 좌표 캐시 저장을 차단하며 기존 위치·운행·집계의 조회와 정정은 유지한다.
- 단말기에는 HTTPS/HMAC 응답으로 정책을 전달한다. 화면은 서버 설정과 실제 단말기 ACK를 구분한다. 절전·오프라인 장치는 다음 통신 전까지 적용 대기다.
- 지원 펌웨어는 적용 시 GPS 파서·UART 대기·RAM 위치 버퍼를 비우고 NVS 저장을 확인한 뒤 ACK한다. 중지 중에는 위치를 파싱·보관·전송하지 않고 정책 확인에 필요한 식별·인증 정보만 보낸다.
- 재부팅·SIM 변경 시에는 허용 상태를 먼저 복원하지 않는다. 서버와 인증된 정책 교환이 성공할 때까지 수집을 닫아 둔다. 저장 실패나 유효하지 않은 정책도 닫힌 상태를 유지한다.
- 재개 시 새 정책 버전과 부팅 내 수집 시작 경계를 사용한다. 이전 버전·시작 경계 이전 버퍼·오래된 위치는 저장하지 않는다. 서버는 단말기 ACK 이후 새 자료만 저장한다.
- 정책은 하드웨어 UUID가 아닌 SIM의 논리 장치에 귀속한다. 같은 SIM을 다른 인증된 하드웨어에 옮겨도 중지 상태를 유지하고 새 하드웨어 ACK를 요구한다.
- 삭제 차단·계정 종료는 수집 재개보다 우선한다. 오래된 화면의 변경 요청은 409로 거부한다. 설정 변경 이력을 보관한다.

## 호환성과 한계

- 기존 펌웨어는 정책에 참여하기 전까지 기존 수집을 유지한다. 한 번 중지하거나 새 펌웨어가 정책에 참여한 SIM은 지원 펌웨어의 확인 없이 예전 방식으로 재개할 수 없다.
- **GNSS 수신기의 물리 전원 차단은 아니다.** 현재 보드는 GPS·LTE 전원 레일을 공유한다. MCU의 위치 파싱·버퍼·송신을 중지하며 수신기 내부 측위 중단을 입증한 것으로 표현하지 않는다. 독립 전원/수신기 명령은 HW 확인이 필요하다.
- 격리 RF 인증 전용 KC 프로필은 정책 서버 없는 기존 시험 동작을 유지한다. 운영·HTTPS 프로필에는 이 예외를 넣지 않았다. KC 이미지를 운영 수집 중지 지원 펌웨어로 배포하지 않는다.
- 서버가 중지 요청을 받은 순간부터 오프라인 장치에 명령이 즉시 도달하는 것은 아니다. 저장 차단은 서버에서 즉시, 단말기 중지는 인증된 다음 통신부터 적용한다.
- 통신을 위한 SIM·하드웨어 식별자와 인증 카운터·정책 ACK 이력은 남는다. 중지는 모든 개인정보의 삭제가 아니다.
- HMAC과 버퍼 시각 검사는 정직한 지원 펌웨어의 재전송을 제어한다. 인증키를 보유한 악성·변조 펌웨어의 허위 시각/좌표까지 입증하는 장치는 아니다.
