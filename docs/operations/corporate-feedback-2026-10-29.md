# 법인차 피드백 실행 계획 — 2026-10-29

대상: gps.serial.kr 법인차 운영. 첨부 1~5는 현재 화면, 6~7은 카택스 참고 화면이다. dev-gps와 Shield는 이번 작업 대상이 아니다. 기존 결함 검토의 보류 항목·보안 제약은 별도로 유지한다.

최종 메뉴: **운영 현황 → 차량 관리 → 사용자 → 지점 → 차량 예약 → 운행 리포트 → 지출 → 설정**. 새 기능은 실제 저장·권한·조회가 구현된 라운드에서 메뉴를 연다.

## 1차 — 현황의 의미와 기본 사용성 (진행 중)

- [ ] 등록 차량 수와 사용 가능 수 구분, 예약 중심 상단·할 일 영역 축소.
- [ ] 현재 수신 / 오래된 위치 / 위치 없음, 마지막 위치 시각 표시.
- [ ] 오늘 거리: 확인된 0 / 수신 없음 / 집계 대기 / 조회 실패 / 일부 집계 구분. 현재 API는 없는 daily_stats도 0으로 반환하므로 원자료 유무를 숨기지 않는다.
- [ ] 장기 미통신·마지막 배터리 저전압·점검 임박·일정 미등록을 먼저 노출. 미작성 운행은 2차의 차량별 통계와 함께 제공한다.
- [ ] 차량과 단말명 열 분리, 미등록 차량 정보를 단말명으로 대체하지 않기. 헤더/행/작업 버튼 정렬.
- [ ] 지도에서 가까운 위치 묶기, 묶음 내 선택 및 목록·지도 강조 연동.
- [ ] 관리 메뉴를 사용자로 변경하고 3번째 배치. 사용자 표와 등록일, 작은 상태 변경 버튼. 운행 기록의 운전자 용어 유지.
- [ ] 차량 상세에서 사진·차량 정보·점검 일정 수정; 단말기 페이지 이동 제거.
- [ ] PC·320/390px, 오류/빈 목록/장기 미수신/실제 0/부분 집계 검증 후 운영 배포.

## 2차 — 차량 독립 등록과 연결 이력

- [ ] 회사 → 차량 등록 → 단말기 연결 → 사용자 배정 흐름.
- [ ] vehicles를 devices/SIM과 분리. 미연결 차량 등록·수정·비활성화. 기존 차량 정보의 이관·검증·복구 절차 준비.
- [ ] 차량명·차량번호·부서·담당자·누적거리·등록일 검색/필터/정렬.
- [ ] 단말기 연결 시작/종료 시각과 대표 단말기. 한 차량에 복수 단말기 허용.
- [ ] 한 단말기의 서로 다른 차량 배정 구간은 중복 금지. 여러 차량 선택은 순차 배정이며 같은 위치/거리를 중복 합산하지 않는다. 동시 저장 경합도 DB에서 차단.
- [ ] 운행·점검·보험·검사·예약은 차량에 귀속. 단말기/SIM 이동 뒤 과거 운행은 당시 차량에 유지. SIM 기반 통신 이력은 기존 원칙대로 보존.
- [ ] 대표 단말기 전환·운행 중 배정 변경의 시간 경계 및 합계 검증. 기존 API/펌웨어 호환.
- [ ] 미작성 운행 수와 바로가기, 차량별 신선도/거리 통계 제공.
- [ ] 소유 계정 격리, 무단 연결 차단, 단말기 해제/재연결, 시간 경계, 과거 기록 보존 회귀 검증.

## 3차 — 사용자·조직·권한

- [ ] 관리자 관리형 부서/직책 목록(추가·수정), 이름·연락처·등록일·활성 상태.
- [ ] 사용자별 운행 가능 차량 및 담당 차량 연결.
- [ ] 관리자/부서 관리자/일반 사용자 권한을 API에서 강제. 기존 staff의 자유 입력 역할을 인증 권한으로 간주하지 않는다.
- [ ] 비활성화해도 운행 기록 보존, 이름/부서 변경의 과거 보고서 정책.
- [ ] 여러 사용자 일괄 등록(CSV 미리보기·행별 오류·중복 방지) 필요 범위 평가.

## 4차 — 지점·지오펜스

- [ ] 전국 주소 검색 → 지도 확인 → 원형/다각형 → 이름·그룹 저장.
- [ ] 본사/지사/거래처/현장 분류, 기존 지오펜스 기능 재사용 범위 확인.
- [ ] 등록일·반경·방문 여부 목록, 출발/도착 지점명 연동.
- [ ] 진입·이탈·체류·방문 기록. 절전/보고 주기 때문에 실제 시각과 수신 시각이 다를 수 있음을 표시.
- [ ] 중첩 펜스/좌표 오류/보고 공백/주소 검색 실패/계정 격리 검증.

## 5차 — 지출

- [ ] 날짜·사용자·차량(선택)·운행(선택)·분류·금액·결제수단·메모·영수증.
- [ ] 유류/정비/숙박 등 일반 지출 허용. 승인대기/승인/반려와 변경 이력.
- [ ] 차량별/부서별/월별 집계 및 CSV/PDF 내보내기.
- [ ] 운행 주유비와 동일 지출 연결: 원장 하나를 집계하고 중복 가산 금지.
- [ ] 승인 권한·금액 검증·첨부 보안·재시도 중복·반려/취소 후 집계 검증.

## 완료 기준

각 라운드는 코드·데이터 처리·회귀 검증·PC/모바일 화면·배포 증빙을 함께 기록한다. 화면만 제공한 기능은 완료로 표시하지 않는다. 운영의 실제 예약·차량·사용자·지출 변경 시험은 격리된 데이터로 먼저 검증한다.
