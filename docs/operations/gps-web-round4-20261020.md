## 변경

- 지원하는 Dashboard 경로를 정확히 판별한다. `/devices/pair`와 trailing slash는 유지하고, 임의 하위 경로·접두어 유사 주소는 홈으로 잘못 보내지 않는다. 없는 주소는 Dashboard를 마운트하지 않고 페이지 없음과 홈 진입점을 표시한다. 기존 `/tools/*` 북마크는 이전 통합 정책대로 검색·hash를 보존해 홈으로 이동한다.
- admin·법인·렌트카·배송 경로는 계정 조회 중, 조회 실패, 권한/유형 불일치를 구분한다. 데스크톱·모바일 모두 안내 본문을 표시하고 홈·계정 확인·재시도를 제공한다. 계정 유형이 바뀌면 이전 특화 화면을 계속 노출하지 않는다. 서버 권한 정책은 기존대로 유지한다.
- Fleet은 1024px 미만에서 차량 목록·지도·차량 상세 전환을 사용한다. 차량 선택은 상세, 운행 선택은 지도로 이동한다. 패널과 지도는 마운트를 유지해 선택과 카메라를 보존한다. 높이는 100dvh, 숨겨진 목록의 가상 스크롤 높이는 음수가 되지 않는다. URL을 선택·검색·필터의 원본으로 사용해 같은 화면으로 들어오는 다른 링크와 브라우저 이동도 반영한다. canvas 등 다른 파라미터와 hash를 보존한다. 잘못된·중복·미소유 장치 ID는 조회하지 않고 안내한다.
- Fleet의 마커 배치는 SDK 준비 완료 후 다시 실행한다. 준비 전에 단말기 조회가 끝나 마커가 빠지는 경쟁을 제거한다. 지도 영역 크기 변경/재표시 시 중심을 보존해 relayout한다. 늦은 운행 이력 응답이 다른 차량 선택을 덮지 않도록 요청 순서를 확인한다.
- 지도 스크립트와 autoload 초기화 요청을 공유하고 각각 12초 시간 제한을 둔다. 실패한 스크립트·미완료 초기화 상태를 정리하여 실제 새 로드로 재시도한다. 홈/Fleet의 공통 지도에는 로딩·실패·재시도 화면을 추가하고 법인/렌트카 지도에도 같은 로더를 사용한다. 오류가 API key 탓이라고 단정하지 않는다.
- 표준 Modal, 공통 alert/confirm/prompt, BusinessDrawer가 포커스·배경 inert·스크롤 잠금을 공유한다. 입력칸 초기 포커스, 양방향 Tab 순환, Escape로 최상위만 닫기, 닫기 후 이전 버튼 복원을 처리한다. Portal을 사용하되 업무 모달의 모바일 하단 배치는 유지한다. 확인창은 취소 버튼에 Enter를 눌렀을 때 확인으로 처리하지 않고 버튼의 기본 동작을 따른다.
