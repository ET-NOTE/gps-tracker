- 관리자 목록: 기존 API의 `items`/`next`는 유지하며 종류·기한 경과·기한 미지정·내 담당·미배정 필터를 추가했다. 기한 필터는 접수/검토 중/추가 확인 상태만 포함한다. 종료된 요청은 기한이 지났더라도 제외한다. ‘내 담당’은 요청자의 관리자 계정 ID로 서버에서 비교한다.

- 화면: 기한 필터 선택 시 초기 ‘접수’ 필터를 풀어 다른 진행 상태도 조회한다. 필터 변경 시 첫 페이지로 이동한다. 조회 취소/화면 종료/조건 변경은 AbortSignal을 전파하고 늦은 응답을 무시한다. 재조회 오류 때 오래된 행이나 ‘자료 없음’을 대신 표시하지 않는다. 페이지 목록은 비활성 시 캐시에 남기지 않는다.
