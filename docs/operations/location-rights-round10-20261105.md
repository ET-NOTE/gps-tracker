# 개인정보 권리 대응 10차 — 추가 개인자료 제공 범위

2026-11-05 · GPS 운영 반영 · `codex/location-business-prep`

## 결과

관리자가 개인정보 열람 요청의 계정 자료를 발급할 때 **추가 연락처·설정 / 거래·구독 요약 / 채팅·AI 이용 이력**을 각각 선택할 수 있다. 요청자와 관리자 모두 발급별 포함 범위를 볼 수 있다. 자료를 발급했다고 요청 전체를 처리 완료로 바꾸지 않는다.

기존 9차 발급에는 새 범위가 자동 추가되지 않는다. 마이그레이션 92의 `sections`는 빈 배열을 기본값으로 한다. 신규 발급도 기본정보·요청 처리이력만 기본 제공하며, 추가 범위는 담당자가 확인 후 선택한다. 재발급 시 이전 계정 자료 권한을 회수한다. 위치 CSV 권한과는 별개다.

## 제공 항목과 제외 항목

| 선택 범위 | 포함 | 제외·별도 검토 |
|---|---|---|
| 추가 연락처·화면·알림 설정 | 등록 전화번호, 인증/대표 여부 및 시각, light/dark 테마, 실험실·안내 확인·경로 화면의 지정된 boolean 설정, 알림 종류와 기준값 | 임의 prefs 전체, 장치별 설정·색상·선택/열람 이력, 허용하지 않은 키/타입. 미저장 값은 기본값으로 추정하지 않음 |
| 거래·구독 요약 | 현재 포인트 잔액, 포인트 원장 증감·거래 후 잔액·분류, 결제 금액/통화/상태/시각, 포인트 및 SIM 충전 요청의 금액·용량·상태·시각, 구독 종류/기간/차감 포인트 | PG 비밀키·가상계좌·영수증 URL·원시 응답·내부 메모·처리자·현재 단말기/SIM 정보. 알 수 없는 자유입력 분류는 `other_review_required`로 표시 |
| 채팅·AI 이용 이력 | 본인 채팅 스레드의 메시지 번호·발신 역할·시각, 본인 AI 분석의 대상 날짜·포인트·생성 시각, AI 사용량의 시각·토큰 수 | 채팅/AI 본문·첨부·관리자 및 장치 식별자·원시 요청·모델/엔드포인트 내부값·서버 로그 |

본문·영수증·회사 자료 등은 타인/회사 정보와 비밀값 분리가 필요한 별도 검토 범위다. 이번 자동 제공에서 제외했음을 명시하며, 해당 항목의 열람 요청을 거절·완료 처리했다는 의미가 아니다.

모든 조회는 본인 `user_id` 또는 본인 채팅 스레드로 제한한다. 과거 거래에 현재 단말기 소유자·SIM 정보·장치명을 조인하지 않는다. 따라서 SIM을 다른 계정으로 옮겨도 본인 거래 요약의 귀속이 바뀌거나 새 소유자 정보가 섞이지 않는다. **SIM 기준 위치 이력 정책, 펌웨어, 수집 정책은 변경하지 않았다.**

기본 제공은 `gps-personal-account-v1`, 추가 범위가 있으면 `gps-personal-account-v2` JSON이다. `coverage`, `unselected_sections`, `excluded`, 범위별 `notice`로 포함/제외를 구분한다. 결제·충전 요청·포인트 원장은 한 거래의 처리 단계일 수 있어 합계로 더하지 않도록 안내한다. 채팅·AI 제공은 본문이 아닌 이용 이력임을 화면과 파일에 표시한다.

## 제한 및 접근 통제

- 기존 활성 계정·본인 세션·현재 비밀번호·공유 시도 제한, 24시간 만료, 회수·요청 취소·반려·계정 이용 종료 차단, no-store를 유지한다.
- 연락처는 200개, 각 거래/채팅/AI 배열은 1,000건까지다. 하나라도 초과하면 전체 선택 응답을 거절하고 담당자에게 나누어 제공하도록 안내한다. 일부 행을 몰래 생략하지 않는다. 기간별 분할 발급 UI는 아직 없다.
- 기본 요청/공개 처리이력은 기존 200/2,000건 제한을 유지한다. 첨부는 기존 파일당 10MB·20개, 검토 해시 및 안전한 파일 읽기 검증을 유지한다.
- 추가 범위는 발급에 저장되고 응답 생성 시 해시를 기록한다. 별도 개인정보 파일을 공개 저장소에 만들지 않는다. 감사 기록은 응답 생성 증거이며 수령·열람 완료의 증거가 아니다.
- 자료는 다운로드 시점에 남아 있는 값이다. 발급 당시 고정된 원본 사본, 모든 개인정보의 전수 제공, 계정 파기 완료를 보장하는 기능은 아니다.
