# 142차 관리자 회사 처리 이력 탐색 — 2026-11-18

## 결과와 범위

관리자의 회사 제출·증빙 확인 이력이 최근100건에서 끊기던 부분을 보완했다. 이제 **50건씩 과거 페이지를 탐색하고, 행위·회사 제출 요청 번호로 필터링**할 수 있다. 기존 회사 요청함141차와 달리 관리자 업무 이력을 조회하는 기능이다.

- ‘회사 처리 이력 보기’를 열 때 조회한다. 이전/다음/처음·새로고침과 조회 취소를 제공하며, 닫기/다른 검토 범위 선택 시 진행 중 HTTP요청을 취소한다.
- 행위는 게시·제출·증빙 응답 생성·검토 반영·보완 요청·회수6종이다. 조건 변경은 첫 페이지로 돌아가며 실제 다음 행이 있을 때만 다음 버튼을 활성화한다.
- 조회 중·취소·실패 시 이전 행을 숨기고 오류와 빈 목록을 구분한다. 취소한 과거 페이지에서 ‘이전 페이지’를 누르면 해당 페이지를 다시 조회한다. 자동 재시도나 주기 조회는 추가하지 않았다.
- 이력ID·요청ID·행위·시각·수행 계정·제출ID·기록 내용을 표시한다. 증빙 응답은 파일 해시를 보여주되 실제 저장/전달/내용 확인 완료와 구분한다. 긴 해시는 모바일에서 줄바꿈하며 기록 내용은 HTML로 실행하지 않는다.
- 새 `GET /admin/privacy/company-reviews/:id/task-events`는 해당 검토 범위의 명시적 메타데이터만 조회한다. 좌표·파일 바이트·회사 명단·본인 요청 내용은 새로 반환하지 않는다. 기존 `/tasks`의 `items`와 최근100 `events` 응답은 호환 유지한다.
- 기존 관리자 TOTP·IP·역할 검사와 접근/응답 감사기록을 적용한다. 이력 조회를 증빙 다운로드 기록으로 남기지 않으며, 승인/실행 권한·원본 수정·삭제 기능을 추가하지 않는다. 회수·만료·상위 요청 취소 후의 과거 이력도 권한 있는 관리자는 조회할 수 있다.

**구현·기능 검증 완료, 운영/dev 미배포**다. 스키마114·기존 정책을 유지하고 APK/펌웨어 변경 및 부하 확대를 수행하지 않았다. 운영 서버·동료의 dev-gps 작업에 접속하거나 변경하지 않았다. 마지막 확인 배포는 API `review137-20261116-r3`, 웹 `android139-web-20261118-r1`, Android1.0.8(14)다.
