# GPS 웹 개선 3차 — 알림 대상과 상태 표시

2026-10-20 KST. 운영 gps.serial.kr 대상. 앞선 인증·기록 보존 작업에 이어 검토 항목 7·10과 Fleet의 차량 번호 표시를 보완했다. dev-gps는 변경하지 않는다.

- SIM 등록창의 긴 설명을 정보 아이콘으로 옮겼다. 마우스 hover, 키보드 focus, 모바일 tap으로 열며 Escape·바깥 클릭·포커스 이탈로 닫는다. 클릭한 설명은 포인터를 옮겨도 유지된다. 모바일은 화면 안에서 너비를 제한하고 긴 내용은 내부 스크롤한다. 등록 항목·SIM 매칭·인증 API는 바꾸지 않았다.
- `?device=ID`는 저장된 필터보다 우선한다. 계정의 장치 목록과 지도가 준비된 후 적용하고 처리한 device 쿼리만 제거한다. 로그인 next 경로는 기존대로 보존되므로 로그인 뒤에도 적용된다. 같은 세션에서 다른 알림으로 이동해도 다시 처리한다. 목록에 없는 ID·잘못된 ID·중복 ID에는 다른 차량으로 대체하지 않고 안내와 단말기 목록 진입점을 표시한다. 서버에 해당 장치를 따로 조회해 타 계정 정보를 확인하지 않는다.
- Fleet은 홈의 `classifyDevice` 판정을 재사용한다. wake만으로 운행 중이라고 표시하지 않는다. 요약은 통신 정상·절전 중·확인 필요·오프라인·수신 전으로 분류하며 행에는 홈과 같은 상세 상태를 표시한다. 30초 시각 갱신과 장치 재조회로 새 이벤트가 없어도 상태가 만료된다. 잘못된 수신 시각은 수신 전, 잘못된 위치 시각은 위치 수신 지연으로 처리한다.
- wake/sleep 이벤트는 단말기 깨어남/절전 진입으로 표시한다. 이동·운행 시작·종료를 단정하지 않는다. Fleet 목록·지도·이벤트 제목도 공통 차량 번호 우선순위를 사용한다. 서버·업무 보고서의 차량 번호 원본 통합은 앞선 배포에 포함됐다.

검증: 웹 101개 테스트(SIM 안내 열기/닫기, 알림 로딩·연속 진입·해제/비정상 대상, 상태 만료·오래된 wake 포함), Vite 빌드. 로컬 브라우저에서 저장된 차량 A → 알림의 차량 B 선택, 없는 단말기 안내, 정보 아이콘·Escape를 확인했다. 390px 화면에서 설명 팝업의 좌우 경계는 33~357px이고 문서 가로 너비는 390px으로 넘침이 없었다.

배포는 `ops/release_native_map_web.py`의 웹 전용 원자적 전환을 사용한다. 산출물·기준 운영 웹 커밋과 파일 SHA를 확인하고 기존 lazy chunk와 uploads 링크를 보존한다. 전환 후 HTML·실행 JS/CSS·진단 페이지·API release를 검증하며 실패 시 이전 웹 링크로 복구한다. API·DB·펌웨어·APK는 이번 라운드에서 변경하지 않는다. 앱 WebView는 새 웹을 로드하면 반영된다.

이번 브라우저 검증은 앱에서 실제 FCM을 발송하거나 Android 알림을 눌러 재현한 실기기 검증은 아니다. 앱이 전달하는 실제 웹 진입 계약 `/?device=ID`를 검증했다.

남은 라운드: 권한 없는 특화 경로/404 안내, 모바일 Fleet 배치, 홈 지도 SDK 오류 복구, 표준 모달 포커스(검토 8·9·15·16·18), Android ZIP/APK·CSV/PDF 다운로드(17). 이는 이번 라운드 완료 범위와 구분한다.
