# 위치정보 권리 처리 — 기존 구조를 유지하는 구현 방향

2026-11-05. 사용자는 기존 구현을 크게 바꾸기 전에 비교적 작은 보완으로 요구사항을 충족하는 방향을 요청했다. 이 문서는 그 기술 구현 기준과 남은 정책 결정을 기록한다. 운영 DB 삭제, 서비스 정책 적용, 펌웨어 변경을 실행한 문서가 아니며 법령 준수 완료 판정도 아니다.

## 구현 기준

1. SIM 기준 논리 장치·기록 귀속, 하드웨어별 인증키, 수신 당시 계정 경계, 차량·단말기 연결 이력은 유지한다.
2. 사용자 연결을 NULL로 바꾸거나 암호화하는 것만으로 탈퇴 자료의 파기가 완료됐다고 처리하지 않는다.
3. 목적·근거·기간이 있는 보관과, 그 근거가 종료돼 파기할 자료를 분리한다. UI 문구만 바꿔 현재 무기한 보관을 정당화하지 않는다.
4. 기존 조회·수정·삭제·공유 철회 기능을 재사용하되, 대상 범위·동시 요청 차단·실패 재시도·완료 검증을 보완한다.
5. 열람·정정 요청은 접수와 본인 확인, 관리자 처리, 결과 통지부터 제공할 수 있다. 위치 일시중지의 서버 차단을 관리자 수동 처리 대기에 맡기지는 않는다.
6. 보관 기간과 회사 업무 기록의 보관 근거 등 아직 확정하지 않은 정책은 임의 숫자나 포괄적 예외로 대체하지 않는다.

## NULL·암호화·익명화의 구분

| 처리 | 이 시스템에서의 의미 | 채택 기준 |
|---|---|---|
| `user_id = NULL` | 계정 외래키 연결 해제. SIM/장치 ID·좌표·시각·경로·운전자 스냅샷·원본 JSON 등이 남을 수 있음 | 개인위치정보 파기의 대체 수단으로 사용하지 않음. 별도로 보관 근거가 있는 행의 계정 연결 해제에는 사용 가능 |
| TLS 또는 저장 암호화 | 전송 도청이나 저장 매체 유출 위험을 낮추는 보호조치. 서버나 키 보유자가 원문을 복구할 수 있음 | 필요한 보안조치로 추진하되 익명화·보관 허가·삭제 완료로 취급하지 않음 |
| ID 해시·가명처리 | 추가 정보 또는 반복되는 식별자를 통해 연결·추론할 가능성이 남음 | 가명정보도 개인정보이며, 가명처리 특례만으로 위치정보법상 철회·파기 의무가 해결된다고 가정하지 않음 |
| 익명 통계 | 합리적으로 이용 가능한 다른 정보와 결합해도 개인을 알아볼 수 없도록 처리한 정보 | 재식별 위험 검토 후 유지 가능 여부 판단. 개인/SIM별 장기 경로나 소수 집단 통계는 익명이라고 단정하지 않음 |

현재 GPS 원본에는 장치 참조·정밀 위치·시각이 함께 있어 NULL만으로 익명화되지 않는다. 키 폐기를 이용한 암호학적 삭제는 모든 원본·파생본·백업이 적절한 별도 키로 보호되고 키 사본까지 제거돼야 검토할 수 있다. 현재 구조에 이를 새로 도입해 탈퇴 처리를 대체하는 것은 최소 변경안으로 채택하지 않는다.

- [ ] SIM 논리 장치에 연결된 처리 정책에 요청 범위·효력 시각·버전·요청자·단말기 적용 확인을 기록한다. 다른 계정의 신규 이용과 이전 계정의 철회 경계를 분리한다.
- [ ] 서버는 중지 범위에 해당하는 위치 저장·이용·제공을 요청 시점부터 차단한다. 진행 중인 요청과 지연된 배치에도 적용한다. 요청 본문·디버그 로그에 좌표를 별도 저장하지 않는다.
- [ ] 서명된 단말기 명령으로 위치 측정/버퍼 적재/전송을 중지하고 재부팅 후 유지한다. 절전·망 단절 시에는 서버 차단과 단말기 적용 대기를 분리해서 표시한다.
- [x] 위치를 포함하지 않는 최소 제어 통신을 정의했다. SIM·하드웨어 식별자, 빌드, 인증 카운터·서명, 연결 검증 해시·기존 명령 ACK, 정책 버전·ACK·부팅 내 시각을 유지하며 위치·모션·진단·전압 자료는 중지 중 보내지 않는다. 제어 통신의 보관 기간과 실제 고지 문안 확정은 별도다.
- [ ] 재개·재부팅·SIM 이동·구형 펌웨어·중지 기간 배치 재전송·공유 링크/실시간 연결을 시험한다. 서버 차단만 끝낸 단계를 단말기 측위까지 중지된 것으로 완료 표시하지 않는다.

### C. 권리 요청 운영

- [x] [9차](location-rights-round9-20261105.md)에서 현재 계정 기본정보·공개 요청 처리이력 JSON과 담당자가 원본을 검토한 개인 서류 제공을 추가했다. 24시간 만료·회수·비밀번호 재확인, 파일 변경/소유권/회사 연결 재검증을 적용한다.
- [x] [10차](location-rights-round10-20261105.md)에서 추가 연락처·지정 설정·거래/구독 요약·채팅/AI 이용 이력을 담당자가 선택해 제공하도록 확장했다. 기존 권한은 확대하지 않고 비밀값·내부 메모·본문·현재 SIM 소유자 정보는 제외한다. 전체 개인정보 제공 완료가 아니며 회사 자료·본문·장치별 설정·사진/영수증·감사·외부 사본 등은 열린 항목으로 유지한다.
- [x] [8차](location-rights-round8-20261105.md)에서 회사·직원 연결의 최소 이력, 회사 자료 검토 대장, 본인 범위·처리 근거·공개 안내·기한·변경 이력을 연결했다. 정보주체와 회사 권한을 분리하고 미해결 범위의 전체 완료를 차단한다. 실제 회사 자료 추출/정정/파기와 보관 정책 확정은 별도이며 담당자 확인을 자동 파기 검증으로 표시하지 않는다.
- [x] 앱에 접수·상태 조회·결과 확인을 추가하고 기존 관리자 화면에 요청 목록을 연결했다. 검증되지 않은 전체 삭제·탈퇴 완료는 API와 DB에서 차단한다. [7차](location-rights-round7-20261105.md)에서 일반 로그인을 복구하지 않는 결과 전용 조회와 만료·회수 가능한 개인 위치자료 제공을 추가했다. 자동 외부 통지, 인증정보 파기 후 본인 확인, 회사·거래 등 전체 자료 제공은 별도다.
- [ ] 기존 CSV·리포트는 추출 도구로 재사용한다. 전체 개인정보 및 수집·이용·제공사실 요청의 완결성과 타인 정보 제외를 별도 검수한다.
- [ ] 담당자, 법정 처리 기한, 본인/대리인 확인, 제한 사유, 전달 방법, 최소한의 처리 증빙을 관리한다. 처리 증빙에 삭제한 위치 원본을 재복제하지 않는다.

- [x] [11차](location-rights-round11-20261105.md)에서 확인된 회사 범위의 처리 보고서·비공개 증빙 제출, 관리자 최신 증빙 확인과 보완·회수·검토 대장 반영을 연결했다. 회사 원본은 자동 변경하지 않으며 제출만으로 전체 요청을 완료하지 않는다. 증빙 보관·삭제 기간과 실제 원본 작업 연결은 별도 검토한다.
- [x] [12차](location-rights-round12-20261105.md)에서 채팅·AI 본문의 수동 구간 선택, 미리보기와 명시적 확인 후 일부 제공을 연결했다. 원문을 복제하지 않고 선택 범위·해시·검토 이력을 저장하며 다운로드 때 계정 귀속·원문 불변·비밀번호·만료/회수를 재확인한다. 회사 자료·사진·영수증은 별도 검토 대상이며 자동 익명화 또는 요청 전체 완료로 표시하지 않는다.

## 남은 정책 확정과 순서

원시 위치의 서비스 보관 기간, 법인 업무 기록의 처리 주체·근거·기간, 거래 자료의 법정 보존 항목, 백업 파기 방법·기한을 회사 담당자가 확정한다. 이 항목은 기존 무기한 보관이나 임의 30일 보관으로 자동 확정되지 않는다.

개발은 **자료 분류와 조회만 하는 영향 점검 → 기존 탈퇴·삭제 함수 보완 → 중지/재개 → 권리 요청 처리 화면·통합 검증** 순으로 한다. 테스트 DB에서 SIM 재연결, 다른 계정, 직원/회사 계정, 중복 요청, 중도 실패, 지연 배치, 백업 복원 시나리오를 검증한 뒤 운영에 적용한다. 기존 TLS 파일럿과 서버 최소 권한 작업은 별도 라운드로 유지한다.

## 공식 근거

- 암호화는 복구 가능성이 있는 보호수단이다. 익명정보의 기준은 합리적으로 다른 정보를 사용해도 개인을 알아볼 수 없는지다. [개인정보 보호법 제58조의2](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=02&joNo=0058&lsiSeq=283839&urlMode=lsScJoRltInfoR)
- 가명정보는 개인정보이며 통계·과학적 연구·공익적 기록보존 특례에는 별도 목적과 처리 절차가 있다. [개인정보보호위원회 가명정보 안내](https://pipc.go.kr/np/default/page.do?mCode=D040010000)
- 불필요한 개인정보 파기, 법령상 보존 예외 및 분리 저장·관리. [개인정보 보호법 제21조](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0021&lsiSeq=283839&urlMode=lsScJoRltInfoR)
- 일시중지 기술적 수단, 열람·정정, 동의 철회 시 해당 개인위치정보와 확인자료 파기. 일반 보관 기간을 철회 자료에 무조건 적용하지 않는다. [위치정보법 제24조](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?lsJoLnkSeq=1029559327)
