# 22B — 기존 법인 지도·리포트·다운로드의 정보주체 범위 연결

2026-11-08. `codex/location-business-prep` / draft PR #248. **구현·격리 검증·후보 패키징 완료, 운영 미배포·실제 푸시 OFF**. 신규 마이그레이션 없이 후보 스키마 106을 유지한다. 운영의 마지막 확인 기준은 18A/schema99이며 이번 라운드에서 운영 DB를 재조회하거나 변경하지 않았다.

## 달라진 동작

22차에서 차단했던 기존 법인 조회 중 아래 7개 경로를 **본인이 확인한 차량·SIM·기간**으로 제한하여 다시 연결했다. 회사 소유자 또는 직원의 현재 권한, 해당 차량의 대표 단말기 연결 기간, 정보주체의 확인·철회·이용/제공 중지 상태를 함께 검사한다. SIM 소유자·예약자·일지의 운전자명은 동의를 대신하지 않는다. 자료 키는 기존 SIM의 `devices.id`이고 하드웨어 인증 UID로 회귀하지 않는다.

| 기존 경로 | 적용 범위 |
|---|---|
| `/corporate/terminals` | 현재 대표 연결의 확인 구간 안에서 마지막 유효 위치만 찾는다. 전역 최근 좌표·정차 이벤트·개인 지도 캐시를 대신 쓰지 않는다. 위치가 없으면 null이다. |
| `/corporate/devices/:id/trips` | 확인 구간별로 운행을 계산하고 서로 다른 운전자·미확인 공백을 연결하지 않는다. |
| `/corporate/devices/:id/trips.csv` | 같은 범위로 서버 CSV를 생성한다. |
| `/corporate/vehicles/:id/trips` | 차량 연결·정보주체 구간을 모두 만족하는 운행만 제공한다. 브라우저 CSV/PDF/인쇄의 새 조회에도 사용한다. |
| `/corporate/fleet/trip-stats` | 확인 구간의 유효 좌표로 다시 집계한다. 기존 전체 일별 합계로 대체하지 않는다. |
| `/corporate/vehicle-stats` | 차량별로 같은 제한을 적용하며 자료가 없는 오늘을0km로 표시하지 않는다. |
| `/corporate/report.xlsx` | 차량 기준으로 제한한 운행과 별도 ‘조회 범위’ 시트를 제공한다. 구 단말기 기준 요청도 제한을 우회하지 못한다. |

기간은 반개구간 `[시작, 종료)`이다. 월간 조회는 한국시간 월 경계, 명시적 기간이 없는 지도는 최근 31일을 사용한다. 한 요청의 기간은최대 367일이다. 통계의 구간별 유효 위치는 10만 건을 넘으면 범위를 줄이도록 거부한다. 이것은 전체 조직 부하 시험 완료나 응답시간 보장을 의미하지 않는다.

확인 구간 경계에서 잘린 운행·종료 미수신 운행은 검토 대상으로 남기고 확정 보고서 합계에 자동 포함하지 않는다. 정정 전 원본 또는 정정 결과가 확인 구간 밖으로 걸친 보정은 적용하지 않는다. 해당 조회에서는 새로운 외부 역지오코딩을 호출하지 않는다.

## 제공 기록과 통보의 결합

1. 조회 전에 기존 건별 취급대장 의도를 내구성 있게 저장하고 허용된 매핑 구간을 고정한다.
2. 지도·운행·통계·파일에 실제 사용한 매핑을 표시한다. 자료가 없는 구간이나 본인이 자기 구간을 조회한 경우에는 제3자 제공 통보를 만들지 않는다.
3. 응답을 내보내기 직전에 차량 배정·현재 권한·정책 및 허용 구간을 재검사한다. 조회 도중 연결 기간이 바뀌면 준비된 응답을 폐기한다.
4. 응답 준비 결과와 사용한 구간의 `location_provision_notices`를 같은 DB 트랜잭션으로 확정한다. 통보 저장이 실패하면 503으로 위치 본문을 내보내지 않는다. 이후 발송은22차 영속 대기열·lease·재시도 경로를 사용한다.

통보의 구간은 **실제 응답에 사용한 매핑의 허용 범위**이며 모든 좌표를 전부 내려줬다는 뜻은 아니다. 원장에는 화면/파일 방법을 구별한다. 브라우저 내보내기는 `download=csv|pdf|print`로 재조회하며 메타데이터만 요구하는HEAD는405로 거부하여 통보를 만들지 않는다. 응답에는 `Cache-Control: no-store`, `X-Location-Scope: confirmed-subject-intervals`를 붙인다.

‘서버 응답 준비’·‘FCM 접수’·‘스마트폰 수신/본인 확인’은 계속 구분한다. 이미 내려받은 파일이나 이미 표시된 화면을 원격 회수한 것으로 주장하지 않는다. 위치 처리와 철회의 경합 잠금 및22차 재시도 의미는 유지한다.

## 웹 사용 흐름

- 운영 현황·법인 지도·차량별/월간 리포트에 **확인한 구간만 포함되어 전체 합계와 다를 수 있음**을 표시한다. 위치가 없으면 확인 구간에 표시할 위치가 없다고 안내한다.
- CSV·PDF·인쇄·월간 내보내기 직전에 현재 권한으로 데이터를 다시 요청한다. 실패하면 화면에 남아 있던 이전 데이터로 파일을 만들지 않는다. 조회 조건 변경·컴포넌트 종료 후 늦게 돌아온 결과도 폐기한다.
- CSV/PDF의 안내·메타데이터·출력에도 범위 제한 문구를 넣는다. CSV는실제 파일의 머리말에 포함한다.
- 구간 제한에 아직 결합하지 않은 위치 정정·원본 증거 조회·일괄 지정 등의 제어는 해당 제한 모드에서 비활성화하고 서버의 기존 차단도 유지한다. 비위치 예약·차량 관리는 기존 흐름을 유지하지만 예약을 실제 정보주체 동의로 자동 간주하지 않는다.
- 기능 OFF에서는 기존 화면을 유지하며 이미 철회된 자료의 우회 차단은22차 규칙을 따른다.
