# 개인정보 권리 대응 13차 — 검토한 이미지 일부 제공

2026-11-05 · GPS · `codex/location-business-prep`

## 제공 범위와 사용 경로

담당자가 원본과 본인 귀속을 대조해 준비한 사진·영수증·문서 페이지에서 공개할 사각 영역만 새 PNG로 제공한다. 회사 검토 대장에 연결하거나 별도 확인한 개인 자료로 구분한다. 회사 파일을 자동으로 찾아내는 기능이나 OCR 자동 가림 기능은 아니다.

1. 플랫폼 관리자가 열람 요청을 검토 중/추가 확인 상태로 두고 처리 기한을 지정한다.
2. **사진·영수증·문서 일부 제공**에서 개인 자료 또는 본인 확인이 완료된 회사 검토 범위를 선택한다. 회사 범위는 확인된 명단과 검토 기간을 표시한다.
3. 원본 내부 참조번호·페이지를 적고 PNG/JPG 한 페이지를 연다. PDF는 담당자가 필요한 페이지를 이미지로 준비한다. 원본과 요청자·회사·기간의 일치는 담당자가 직접 대조한다.
4. 드래그 또는 좌표 입력으로 공개할 영역을 지정한다. 기본 선택은 없으며, 제공 범위와 제외 사유를 적는다.
5. 미리보기에서 실제 제공할 이미지를 확인한 뒤 **원본·본인 범위 대조**, **타인 정보 제외·제공 범위 확인**을 각각 체크하여 24시간 제공한다.
6. 요청자는 **내정보 → 개인정보 → 해당 요청 → 검토한 이미지·일부 제공**에서 현재 비밀번호 확인 후 PNG를 저장한다. 실패/성공 후 비밀번호 입력은 비운다.
7. 관리자는 발급을 회수할 수 있다. 발급만으로 열람 요청 전체를 완료하지 않는다.

## 구현 경계

- 브라우저는 원본 파일을 로컬에서 해석하고 선택 영역의 RGB만 보낸다. 선택하지 않은 픽셀은 전송 전 검게 바뀐다. 서버도 영역을 재검증하고 선택 영역만 복사해 새 RGB PNG를 인코딩한다.
- 출력 PNG에는 IHDR·IDAT·IEND만 포함한다. 원본 EXIF, 투명 알파, PDF 텍스트/레이어는 복사하지 않는다. 같은 안내와 선택 결과의 미리보기 해시가 일치해야 발급할 수 있다.
- 원본 파일 SHA-256과 내부 참조는 수동 대조의 근거로 남긴다. 서버가 실제 원본 저장소에서 해당 파일을 가져와 귀속·내용을 검증한 증명은 아니다. 외부 원본의 사후 변경/삭제도 자동 감지하지 않는다. 잘못 제공한 경우 회수해야 한다.
- 회사 제공은 같은 요청의 본인 확인된 검토 대장·명단·revision에 묶인다. 회사 검토 revision 변경, 제외/제한 처리, 회사 계정 이용 종료 시 제공을 차단하고 임시 파일을 제거한다. 현재 SIM 소유자에게 이전 자료를 이전하는 로직은 추가하지 않는다.
- 요청자 본인 계정, 현재 비밀번호, 요청/IP별 제한을 적용한다. 요청자 목록에는 내부 참조·원본 해시·회사 번호·선택 좌표·담당자 번호를 노출하지 않는다.
- 발급 시 같은 관리자에게 1시간 이내의 동일 미리보기 이력이 있어야 한다. 요청 revision 잠금으로 동시 발급의 중복 처리를 차단한다. 이미지 인코딩 동시 작업은 2개로 제한한다.
- 입력은 PNG/JPG 6MiB 이하, 한 변 2048px 이하·100만 화소 이하, 공개 영역 최대 30개다. 서버는 RGB 크기·영역·본문 4.1MB를 검사한다. 요청당 최대 10회 발급, 서버의 임시 이미지 전체는 64MiB 이하로 제한한다. 큰 문서는 분할 요청으로 처리한다.
- 응답은 attachment·application/octet-stream·nosniff·no-store, private로 제공한다. 다운로드 응답 생성은 사용자가 파일을 열었다는 증명이 아니다. 이미 다운로드한 사본은 원격 회수할 수 없다.

## 임시 파일과 이력

새로운 제공 이미지 바이트만 별도 테이블에 임시 저장한다. 기본 만료는 24시간이다. 회수·요청 취소/거절·요청자 이용 종료·회사 검토 변경 시 DB 트리거가 임시 바이트를 제거한다. 만료 즉시 다운로드를 차단하며 API 시작 시와 매 60초 정리 작업으로 만료 바이트를 제거한다.

발급 메타데이터·선택 영역·해시·안내·검토/발급/회수/응답 생성/파일 제거 이력은 별도 보관한다. 이력의 임의 수정·삭제와 활성 제공본의 바이트 변경·삭제를 차단한다. 원본, 백업 사본, 이력까지 모두 삭제한 것은 아니며 익명화 또는 전체 파기 완료로 표시하지 않는다. 보관 근거·기한과 승인된 파기는 열린 항목이다. 내부 참조와 안내에는 필요한 최소 정보만 적는다.
