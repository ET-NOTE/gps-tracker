시험용 빌드 구현 완료 밴드 실측 완료 — Cat-M1 B5 인증 밴드 확정 대기 (시험소 답변) 모듈 KC 인증서 수배 중

1. 왜 시험용 빌드가 따로 필요한가

KC 무선(RF) 시험은 상용망이 아니라 콜박스(기지국 시뮬레이터 — Anritsu MT8821C, R&S CMW500 류)에 단말을 붙여 진행한다. 콜박스는 시험용 PLMN(001/01)과 시험용 USIM으로 RRC 등록까지만 세우고, 데이터 세션(PDP/APN)은 붙여주지 않는 경우가 많다.

우리 운영 펌웨어는 "서버 POST 실패 → 복구 에스컬레이션" 구조라, 콜박스 환경에서 그대로 돌면 모뎀 전원을 12초씩 끊는 railCycle과 esp_restart가 주기적으로 발동해 측정 자체가 불가능해진다. 시험소 상담 기록(for_kc.txt)에서도 "이 유형이 가장 흔한 시험 지연 원인"으로 지목됐다. 그래서 이 동작들을 통째로 끄는 시험 전용 빌드를 만들었다.

2. 구현 — KC_TEST_BUILD 플래그

idf_caltest/main/config.h 맨 아래의 플래그 하나로 전환한다. 기본값은 0(운영)이고, 시험 직전에만 1로 켠다. 별도 브랜치가 아니라 플래그 게이트라 운영 코드와 항상 같이 유지보수된다.

3. 시험소 가기 전 — 빌드·플래시 절차

  1. 플래그 켜기

    idf_caltest/main/config.h 맨 아래 #define KC_TEST_BUILD 0 → 1

  2. 빌드 & 플래시 
    idf.py build
idf.py -p COMxx flash
  3. 증빙 캡처

    부팅 로그에서 [KC] band-lock evidence: … 라인을 저장 (4절 참고)

  4. 시험 종료 후 반드시 0 원복 → 재빌드

    확인: grep "KC_TEST_BUILD 1" idf_caltest/main/config.h 결과가 없어야 함. 과거 관찰용 토글(TIMER_WAKE)이 운영본에 남아 안전망이 꺼진 사고가 있었다 — 같은 함정.

4. 밴드 락과 인증 범위 증빙

전파법상 인증 범위는 SIM이 아니라 "기기가 송신할 수 있는 주파수" 기준이다. 펌웨어에서 밴드를 제한하고 그 증빙을 제출하면 인증 대상 밴드를 줄일 수 있고, 밴드 수가 시험 비용을 좌우한다 (2밴드 견적 약 270만원 → 1밴드로 축소 시 유의미한 절감). 

// config.h — 시험소 견적 확정 후 조정
#define KC_BAND_CATM   "5"   // 인증표 Cat-M1: B5 / B8 / B3 중
#define KC_BAND_NBIOT  "5"   // 인증표 NB-IoT: B5 / B3 중
#define KC_CATM_ONLY   1     // NB 미인증이면 1 (CMNB=1)

부팅 시 락을 적용한 뒤 AT+CBANDCFG? 응답을 그대로 로그로 뽑아준다. 이 캡처 + 제조사 선언서 조합이 "펌웨어 밴드 제한" 증빙이 된다. 

[KC] band-lock evidence: AT+CBANDCFG? +CBANDCFG: "CAT-M",5 +CBANDCFG: "NB-IOT",5 OK

실측 근거

2026-08-27, 실단말(device 3005)이 1NCE 로밍으로 Cat-M1 Band 5에 등록됨을 서버 telemetry(band:"M1-B5")로 확인. 밴드 필드는 매 세션 자동 수집되므로(PR #216), 전 단말의 실사용 밴드를 서버 데이터로 증빙할 수 있다.

주의 1 — CBANDCFG는 모듈에 남는다

밴드 락은 SIM7080G NVRAM에 저장된다. 시험 빌드를 돌린 모듈을 일반 개발로 되돌릴 땐 docs/kc_test_build.md의 복원 커맨드로 전체 밴드를 풀어야 한다.

주의 2 — 인증 후 양산 펌웨어도 락 유지

밴드 제한을 근거로 인증을 받으면 양산 펌웨어도 그 제한을 유지하는 것이 원칙이다. 인증 밴드 확정 시 운영 빌드 bringUp에 락을 상시 반영하는 후속 작업이 필요하다 (미착수).

5. 시험소 제출 샘플 체크리스트

  • 정상 완제품 샘플 2~3대 — 복사성 방출 시험용
  • RF 커넥터 인출 지그 샘플 1대 — 전도성 시험용. 안테나 급전점에 동축(RG178) 직결. 제작 전 시험소와 사양 협의
  • 시험용 펌웨어 — 본 KC_TEST_BUILD (워치독 off · COPS=0 · 밴드 락)
  • 12V 전원 케이블 (차량용)
  • 밴드 락 증빙 — [KC] band-lock evidence 캡처 + 제조사 선언서
  • SIM7080G 모듈 KC 인증서 — 대리점(에드웍스 등)에 요청, 수배 중
  • 동작 설명서 — KC 빌드는 전원 인가만 하면 시험 상태 진입 (별도 조작 불필요)

6. 시험소에 확인할 것 (미해결 — 답변 대기)

Q1밴드 제한 증빙(선언서 + 펌웨어 로그)을 인정하는가?
인정되면 1밴드로 재견적 요청 — 비용이 갈리는 핵심 질문. 실측상 B5 단일이 유력.
Q2SIM7080G 모듈 KC 인증서 제출 시 무선 시험이 면제되는가?
면제되면 콜박스 시험 자체가 대폭 축소. 안테나 조건 충족 방법도 함께 확인.
Q3RF 테스트 모드 펌웨어가 별도로 필요한가, 콜박스 전력제어로 충분한가?
콜박스는 RRC 전력제어로 최대 출력을 올릴 수 있어 보통은 불필요. 요구 시 SIMCom RF Test 문서 수배.

7. 사전 스캔 (참고 — 자체 EMI 점검)

시험소 방문 전 DSA815-TG로 자체 복사 노이즈를 훑을 때의 전문가 권고 세팅: 30 MHz–1 GHz, RBW/VBW 100 kHz, Ref −20 dBm, Positive Peak + Max Hold 켜고 근접장 프로브로 보드를 수 분간 훑는다. 근접장 측정값은 규격(dBμV/m)과 직접 비교할 수 없고, 핫스팟 위치 특정과 대책 전후 상대 비교에만 쓴다.

장비 한계

DSA815-TG 상한은 1.5 GHz — B3(1.7/1.8 GHz)과 GPS L1(1575.42 MHz)은 이 장비로 못 본다. GPS self-desense 디버깅이 필요해지면 3 GHz급 분석기가 별도로 필요하다.
