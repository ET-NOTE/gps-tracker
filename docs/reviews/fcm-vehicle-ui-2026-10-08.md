# FCM 안내 및 차량 관리 화면 통일

## 변경 내용

- 절전 중 위치 갱신 중단, 확인된 기상 사유, 반복된 GPS 미확보, 전압 저하 재시작 기록을 사실에 맞게 설명한다. 수신 지연만으로 통신 단절을 단정하지 않는다.
- 예약 시작·종료와 렌트 반납 예정·미완료 계약 알림을 FCM에 연결했다. 예약/반납 알림을 각각 끌 수 있다. 새 설정의 기본값은 켜짐이며 일정이 등록된 차량 소유자만 수신한다. 임차인 전화번호로 메시지를 보내지 않는다.
- 큐 적재와 발송 재시도 시 현재 소유권·알림 설정·예약 취소·반납 완료·일정 변경·시간 경과를 재확인한다. 서로 다른 예약은 별도 알림으로 유지한다. 일정을 변경하면 관련 알림 처리 표시를 초기화해 새 일정으로 안내할 수 있다.
- 예정 시각은 한국 시간으로 표시한다. 계약 연락처·운전자 개인정보를 알림 본문에 추가하지 않는다. 기존 알림 채널과 장치 화면 이동을 사용한다.
- 차량 정보를 사진, 차량 정보, 정비 일정, 보험·검사로 묶었다. 공통 입력폼·버튼·오류/성공 안내, 폭에 따른 1/2열 배치, 사진 선택/해제 UI를 적용했다. 사진은 즉시 저장되고 나머지 항목은 저장 버튼으로 반영된다.
- 위치 공유의 브라우저 기본 팝업을 공통 대화상자와 화면 내 입력폼으로 교체했다. 구매 비용 표시, 취소 시 미구매, 불러오기 실패 안내·재시도, 복사 권한이 없을 때 직접 복사할 주소를 제공한다.
- 내정보의 계정·비밀번호·데이터 정리·전화번호 관련 기본 팝업을 공통 대화상자로 통일했다. 비밀번호 오류로 단정하던 실패 문구도 서버 오류에 맞게 표시한다.
- 공통 입력폼의 라벨·도움말 연결과 터치 크기를 개선했다. 법인·렌트 패널과 공통 모달에도 터치 크기와 모바일 입력 글자 크기를 적용했다.
