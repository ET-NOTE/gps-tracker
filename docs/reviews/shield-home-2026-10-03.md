# Shield 홈 메인 문구와 제품 소개 배치

요청한 제목 두 줄과 서브 문구를 그대로 적용했다. 참고한 https://www.autonics.com/kr/main 의 왼쪽 제품 설명·오른쪽 제품 비주얼·넉넉한 여백 구성을 Shield의 기존 청록색 토큰과 쉴드 SVG 그림에 맞췄다. 참고 사이트의 이미지·슬라이더는 가져오지 않았다.

- 제목: `LTE와 GPS를 하나의 쉴드에` / `센서 확장까지 더 간편하게`
- 설명: `USIM 기반 LTE 통신과 GPS 기능을 지원하며,` / `다양한 센서를 추가로 연결해 여러 IoT 프로젝트를 손쉽게 구현할 수 있습니다.`
- 큰 화면은 설명/제품 그림 1.4:1 열, 최소 높이 460px, 본문 16px. 모바일은 한 열과 14px 설명으로 전환하며 한글 어절을 보존한다.
- 로컬 브라우저 320/390/768/1024/1440px에서 제목 두 줄, 페이지 가로 넘침 없음 확인. 1024px 이상 설명 두 줄, 좁은 화면은 자연 줄바꿈 확인. 시작 가이드·예제 보기 버튼의 목적 페이지 이동과 기존 데모 표시 확인.
- 변경은 HomePage.jsx와 홈에 한정된 CSS다. API, DB, GPS/KC, 결제와 실물 펌웨어는 수정하지 않는다.
