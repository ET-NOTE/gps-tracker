# 연결 확인 알림 반복 중단

## 문제와 변경

운영은 30분 미수신 후 첫 offline 이벤트를 만들고, 실제 수신이 돌아오지 않아도 24시간마다 새 이벤트를 만들었다. 일부 단말에서 7일간 7개 offline 이벤트를 확인했다. 최근 48시간에는 offline 이벤트 19개와 성공 발송 22건이 있었으며 일부 계정은 앱 설치 2개로 각각 수신했다. 같은 installation_id의 활성 토큰 중복은 없었다.

- 기본 최초 안내를 24시간으로 변경하고, 실제 수신이 재개되기 전까지 동일 단계의 안내를 반복하지 않는다.
- 마지막 실제 수신 시각을 기준으로 사용자·단말·단계별 영수증을 DB에 저장한다. 여러 워커, 서버 재시작, 날짜 경과, 이벤트 이력 삭제로 재발송되지 않는다. 장치 행 잠금과 이벤트/영수증 트랜잭션으로 동시 수신·소유권 변경과의 경합을 막는다.
- 절전 여부는 마지막 wake/sleep_enter로 판정해 다른 진단 이벤트 때문에 절전 단말이 offline으로 재분류되지 않게 한다. stuck/lost는 여전히 진단 기록이며 푸시를 새로 활성화하지 않았다.
- 알림 설정에서 30분·1시간·6시간·12시간·24시간·2일·7일 또는 직접 입력(5~10080분)을 선택한다. 반복 주기가 아닌 최초 안내 시점임을 설명한다. 기존 30분 기본값은 1440분으로 이관하며 다른 값은 보존한다.
- 긴 미수신 시간은 일/시간으로 표시한다. 예: 36035분 → 25일. GPS 미확보만으로 LTE 장애라고 단정하지 않는다.
- 마이그레이션 68은 진행 중인 미수신 상태의 기존 이벤트를 영수증에 이관하고 이전 정책의 대기 중 연결 알림을 취소한다. 과거 이벤트는 보존하며 휴대폰에 이미 표시된 알림을 원격 삭제하는 작업은 아니다.
