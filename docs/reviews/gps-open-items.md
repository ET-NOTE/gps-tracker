# GPS 열린 항목

2026-10-22 KST 사용자 결정: 아래 항목은 **열림·보류**로 유지한다. 완료나 위험 해소로 분류하지 않으며, 이번 방향 마커 수정 라운드에서는 작업하지 않는다.

| ID | 항목 | 상태·재개 시 확인 |
|---|---|---|
| GPS-OPEN-01 | 절전 정기 보고 실기기 검증 | 열림·보류. 24시간 경과 실제 기상·수신, 원격 주기 저장과 재부팅 후 유지. 사용자가 직접 확인하기로 함. 자동 모니터링/재부팅/재플래시 없음. |
| GPS-OPEN-02 | 운영 단말기 인증 펌웨어 전환 | 열림·보류. 기존 단말기의 순차 갱신 및 legacy 수신 허용 범위 종료 검증. |
| GPS-OPEN-03 | 전송 기밀성 | 2026-11-04 [위치정보사업 준비 F1](../operations/location-business-preparation.md)에서 별도 HTTPS 파일럿 개발 재개. 기존 운영은 HTTP+HMAC. 실기기 인수·운영 전환은 열림. |
| GPS-OPEN-04 | SIM 등록의 물리 점유 증명 | 열림·보류. SIM 끝8자리와 최근 인증 접속/소유권/시도 제한은 적용하지만, 입력만으로 물리적 SIM 보유를 암호학적으로 증명하지 않음. |
| GPS-OPEN-05 | Fleet 자정 경계 운행 표시 | 열림·보류. 자정 이후 종료 날짜 생략을 날짜 범위 표시로 통일. |
| GPS-OPEN-06 | Fleet 내부 이벤트 문구 | 열림·보류. stuck 등 내부 이벤트명을 사용자용 설명으로 통일. |

2026-10-31 갱신: GPS 기능 개선 14차 최종 회귀를 완료했지만 위 6개 항목의 **열림·보류** 상태는 유지한다. 전체 범위와 운영 결정은 [14차 완료·검증표](gps-final-regression-2026-10-31.md)를 참조한다. 위 보류 항목을 자동으로 재개하지 않는다.
