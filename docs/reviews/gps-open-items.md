현재 후보는 `activation_ready=false`. [116차 누적 전환·복구 리허설](../operations/location-business-cumulative116-20261111.md)은 API 1개·합성 tmpfs DB에서 통과했지만 위 세 항목을 닫지 않는다. 최신 115 API·웹을 99→112 전환에 결합하고 단계별 실패·호환 복구·철회/파기 재적용을 검증했다. 운영 적용 전 다음 작업은 실제 VPS 자원·공유 I/O·접근기록 시작/완료 지연 계측과 DB 임시파일/swap 보호다. 새로운 실측 없이 운영 정비시간이나 성능을 보증하지 않는다. 백신/WAF 실무검증은 [인프라4차](../operations/infra-round4-antivirus-waf-20261111.md)의 보류 상태를 유지한다.

2026-11-06 인계 보충: 아래 시험 시점 이후 [권리 처리 6차](../operations/location-rights-round6-20261105.md)에서 단말-520211을 `1c8e692`의 `https-pilot`으로 갱신하고 실내 수집 중지/재개를 검증했다. 절전 OFF는 유지하며 아래 운영 인수·전체 전환의 열린 상태를 닫지 않는다. 최신 운영 및 후속 작업은 [인계 문서](../operations/HANDOFF.md)를 따른다.
