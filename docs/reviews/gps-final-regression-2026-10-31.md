# GPS 14차 완료·검증표

2026-10-31 KST. GPS 기능 개선 단계의 최종 회귀와 발견 결함 수정을 완료하고 `gps.serial.kr`에 웹을 반영했다. Shield와 dev-gps는 변경하지 않았다. 운영 데이터 쓰기 시험은 하지 않았고, API 변경 동작은 격리 DB·화면 흐름은 모의 데이터로 검증했다.

## 이번 수정

월간 요약의 정수 반올림 때문에 0.07km가 0km가 되고, 기록이 없거나 미확정인 차량도 개인 100%로 표시되는 문제를 수정했다. 확정 기록 없음(`—`)·실제 0km·짧은 거리를 구분하며 확정/제외 건수를 제공한다. 용무가 지정되지 않은 거리는 `기타·미분류`다. CSV/PDF에도 같은 집계 상태와 공란/0/소수점 기준을 사용한다. 기존 입력 주유비는 거리 확정 여부와 별도로 유지한다. 차량·단말·SIM 배정이나 원본 운행 상태를 수정하지 않았다.

## 완료와 보류의 구분

활성 GPS 기능 개선 1~14차는 검증한 범위에서 완료했다. 다음 항목은 별도 열린 상태이며 완료로 간주하지 않는다.

- 운영 결정: 외부 정기 백업 보관처/일정, 전체 복구 시험 주기, 5GiB 경고선 아래 디스크의 증설 또는 검증된 과거 산출물 정리. 기존 dump의 해시 일치는 전체 복구 시험을 대체하지 않는다.
- 제공 범위 제한: 차량/단말 연결 경계를 걸친 보정, 비용/운전자/용무가 있는 운행 병합 재배분, 과거 지점 방문 소급/지연 GNSS 재계산, 지점 전용 FCM, 실물 지점 진입·이탈, 최신 법정 서식 적합성 판정.
- 실결제·환불·외부 알림 전송은 이번 기능 회귀의 확인 대상이 아니며, 통과했다고 표현하지 않는다.
