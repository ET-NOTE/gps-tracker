# Shield 관리자 화면·편집기 검토

## 수정

- 게시물·FAQ 및 계정/장치 편집의 미저장 변경을 비교하고, 관리자 탭·다른 페이지·뒤로 가기·편집 닫기 전에 계속 편집/변경 버리기를 선택한다. 새로고침·탭 닫기는 브라우저 beforeunload 경고를 연결했다. 저장 중에는 이동을 막고 업로드 중 편집을 버리면 기존 취소 처리를 따른다.
- 현재 관리자 탭을 다시 눌러도 편집기를 닫지 않는다. 시작가이드 지정과 초대코드 발급은 진행 중 편집을 유지한다. 저장 성공 후에는 보호 상태를 해제한다.
- 사용자 검색 조건이 장치/감사 등 다른 조회에 전달되지 않도록 분리했다. 탭 전환 시 조건을 초기화하고 검색은 250ms 지연, 서버와 같은 100자 제한을 적용했다.
- 테이블 조회 중 상태와 실제 빈 결과를 구분한다. 사용자 통계·상세·목록 및 FAQ의 새 조회는 이전 오류를 지우며, 통계 실패 시 0이 아닌 미확인 표시를 한다. FAQ 목록 감소 시 유효 페이지 범위로 보정한다.
- 저장 상태와 공개/초안 표시를 추가하고 요약은 여러 줄 입력으로 변경했다. 미리보기의 단계 이동은 미리보기 안에서만 스크롤한다.
- 1NCE 설정값 존재만으로 연결 성공을 표시하던 문구를 '설정됨'으로 바로잡았다.

## 검증

- 격리된 로컬 프론트/etcom-hub 미리보기 API에서 게시물 수정 → 탭/헤더 링크/뒤로 가기/닫기 경고 → 계속 편집 시 입력 유지, 변경 버리기 시 이동을 확인했다.
- 시작가이드 설정 변경 후 작성 중 글 유지, 현재 탭 재선택 유지, 새 게시물로 전환, 로컬 초안 저장 성공 후 경고 해제를 확인했다. 운영 게시물에는 검증용 내용을 저장하지 않는다.
- FAQ 새 글 작성 후 닫기/탭 전환 보호, 사용자 검색 후 장치 목록 정상 조회를 확인했다.
- 검증 전용 SSH 터널을 중단해 조회 오류를 재현하고 복구 후 새로고침으로 오류가 사라지고 통계/목록이 돌아오는 것을 확인했다.
- 320px 화면에서 경고창과 편집기 가로 넘침 없음, Escape로 편집 유지, 요약 textarea 및 공개 표시를 확인했다.
- 미리보기 단계 전환 전후 편집 페이지 scrollY가 유지된다.
- 새로고침 경고는 코드 연결을 검토했으며 브라우저별 강제 종료 시 내용 복원은 제공하지 않는다. 자동 임시저장 기능은 이번 범위에 포함하지 않는다.

Shield 프론트만 변경한다. API·DB 스키마·결제·1NCE 주문 로직·GPS/KC 수신에는 변경이 없다.
