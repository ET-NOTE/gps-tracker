# Shield 포인트·운영 관리 반영 기록

## 범위

- 계정별 포인트 충전 모달(10,000/30,000/50,000/100,000P), 결제 내역/결과 재조회.
- 장치/요금 안내에서 공통 USIM 모달. 잔액 부족, 처리 중 요청, 현재 잔량을 구분.
- 카카오톡/이메일 문의 선택은 준비 중 placeholder이며 실제 발송하지 않는다.
- 관리자 사용자 집계/상세/현재 목록 CSV, FAQ 공개·숨김·보관·복원과 변경 감사.
- 게시물 편집은 실제 사용자용 단계 컴포넌트를 저장 전 미리보기에 사용한다.
- 스키마 9: FAQ 및 포인트 주문. 결제 키/주문/계정/금액 결합, 중복 승인·적립 방지,
  불확실한 결제 결과는 조회로 조정한다. 결제 콜백 쿼리는 nginx 접근 로그에서 제외한다.

## 활성화 대기

사용자는 시안 가격을 적용하되 확정 USIM 상품·가격은 별도로 전달하기로 했다.
시안마다 용량·가격이 다르므로 현재 USIM 신규 판매는 닫혀 있다. 기존 500MB 공급자
어댑터를 1GB/5GB 등으로 표시하지 않는다. 확정 카탈로그와 공급자 용량 이행 연결이 필요하다.
응용 프로젝트도 준비 중이다.

Shield 전용 Toss 키는 아직 설정되지 않았다. 운영 포인트 충전은 준비 중이며
실제 결제 활성화에는 운영 키/도메인 및 취소·환불 시 포인트 대사 절차가 필요하다.
실제 결제나 1NCE 충전 요청을 검증에 사용하지 않았다.
